# Inferno Corridor

A small first-person 3D action game: clear each arena, then reach and disarm its reactor before the 15-second countdown expires. Fight through ten levels with energy weapons, sword-wielding enemies and heavy hammer brutes.

[Download a release](https://github.com/pigslam/inferno-corridor-releases/releases)

Choose the ZIP for your computer, or download **All-Platforms** to get every version together:

| Download | Launch after extracting the entire ZIP |
| --- | --- |
| Windows x86_64 | `Windows/Play-Windows.cmd` |
| Linux x86_64 | `Linux/Play-Linux.sh` |
| Mac Universal (Apple Silicon and Intel) | The application inside `Mac/` |
| All-Platforms | The launcher for your system in its folder |

Godot is bundled. No installer or separate engine download is required. Windows and Linux launchers use Vulkan and include an OpenGL compatibility option. The Mac app uses Metal.

WASD moves, the mouse aims with inverted Y, Shift sprints, Space jumps (grounded single jump), and left click shoots. Esc releases the pointer. Press E beside the reactor to disarm it; R restarts after death.

These are preview releases. Windows has been tested using Proton on Linux; native Windows testing is pending. Earlier Mac builds were tested on an M5 MacBook Air; Intel Mac runtime testing remains pending. Read each release's notes for its exact validation status. Windows builds are unsigned. Mac builds are ad-hoc signed and not Apple-notarized; the included README explains first launch.

Each release includes SHA-256 checksums, version metadata and notices for Godot and the Quaternius assets. Older releases stay available on the releases page. Extract updates into a new folder so their executable and game data stay together.

This repository hosts public downloads and their instructions. The development source repository is private. GitHub's automatically generated **Source code** archives contain this download repository's documentation; use the named game ZIPs to play.
